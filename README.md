# Inside the Annex

An immersive React and Tailwind CSS storytelling website inspired by *The Diary of a Young Girl* by Anne Frank.

The experience is designed as a restrained digital museum archive: cinematic, historical, accessible, and focused on the psychological narrowing of freedom while hiding in the Secret Annex.

## Features

- Fullscreen atmospheric hero with grain, dust, attic light, and type-led introduction
- Scroll-driven 1933-1947 narrative timeline that visually narrows and darkens
- Emotional diary theme cards with minimal interactions
- Interactive Secret Annex floor plan with room context
- Parallel inside/outside narrative section
- Fragmented ending and remembrance reflection
- Ambient audio toggle, scroll progress, responsive layout, and reduced-motion support
